# Issue Templates

To maintain code quality and process bug reports smoothly, GitHub Issue Templates are available in `.github/ISSUE_TEMPLATE/`.

### Available Templates

- **[Bug Report](.github/ISSUE_TEMPLATE/bug_report.md):** Report bugs, unexpected mixin krasj, or undefined mixin errors.
- **[Feature Request](.github/ISSUE_TEMPLATE/feature_request.md):** Suggest new mixins, utility maps, or WCAG enhancements.

### Guidelines for Submitting Issues

1. **Check Existing Issues:** Search open and closed issues before opening a new ticket.
2. **Provide Reproducible Sass Snippets:** Include the exact `@use` imports and `@include` mixin calls.
3. **Include Full Error Stack Traces:** Attach compiler log outputs (e.g., Dart Sass or Vite build logs).
